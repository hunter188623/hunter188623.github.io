# HUNTER — personal security research website

## Preview locally
Open `index.html` in a browser. For a local server, run:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Publish with GitHub Pages
1. Extract this ZIP.
2. Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder to the root of your GitHub Pages repository.
3. Commit and push.
4. In GitHub, open **Settings → Pages** and select your deployment branch if Pages is not already enabled.

## Customize
- Update the GitHub URL in `index.html` if your profile URL differs.
- Add real writeups in the `#writeups` section. The current empty state is intentional; no writeups were invented.
- The supplied reference image is cropped to use its hacker workspace artwork as the hero background. Navigation and text are real HTML, not baked into the image.
